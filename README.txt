NOROESTEBIO GOMA / DAIRYGRIP — V2 DE TRABAJO

PWA interna para visitas, medición por zonas, fotografías reales, presupuesto y seguimiento de pedido.

Cambios principales frente a V1:
- Fotografías reales comprimidas y guardadas en IndexedDB, vinculadas a cada zona.
- Guardado automático y borradores recuperables.
- Zonas rectangulares e irregulares.
- Campos para arrobadera/guía, postes, puertas, bebederos, cortes y obstáculos.
- Historial de obras editable.
- Presupuesto imprimible/PDF.
- Configuración editable de tarifa y accesorios.
- Copia de seguridad JSON de datos (las fotos permanecen localmente en el dispositivo).
- Migración inicial de datos desde nb_goma_v1 cuando exista.

Regla comercial inicial heredada: PVP 68 €/m² + IVA, porte incluido; distribuidor hasta 10%.

IMPORTANTE: esta versión sigue siendo local. No sincroniza automáticamente iPhone y PC. La sincronización cloud será una fase posterior.
